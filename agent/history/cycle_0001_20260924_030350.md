**Why:** The current implementation is incomplete, causing `None` returns and runtime errors when the dialogue engine tries to rank roots.  

```python
# root_semantics.py
def cosine(a, b):
    """Return the cosine similarity between two vectors."""
    a = np.asarray(a, dtype=np.float64)
    b = np.asarray(b, dtype=np.float64)
    na = np.linalg.norm(a) + 1e-9  # avoid division by zero
    nb = np.linalg.norm(b) + 1e-9
    # Clip to [-1, 1] to protect against numerical drift
    return float(np.clip(np.dot(a, b) / (na * nb), -1.0, 1.0))
```

#### 2️⃣ `dialogue_engine.py` – robust root loading  
**Why:** Duplicate or malformed roots can lead to biased selection and unnecessary warnings; a clean, deterministic list improves reproducibility.  

```python
# dialogue_engine.py
def load_roots():
    txt = Path("arabic_db/roots.txt")
    if txt.exists():
        lines = [ln.strip() for ln in txt.read_text(encoding="utf-8").splitlines()]
        # Keep only three‑letter strings composed of known phonemes
        valid = {r for r in lines if len(r) == 3 and all(c in PHONEMES for c in r)}
        if valid:
            sorted_roots = sorted(valid)  # deterministic order
            print(f"[dialogue] loaded {len(sorted_roots)} unique roots", file=sys.stderr, flush=True)
            return sorted_roots
    # Fallback demo roots (also deduplicated & sorted)
    fallback = sorted({"ابت", "عرب", "كتب", "علم", "نور", "صوت", "كون", "روح"})
    print("[dialogue] fallback demo roots", file=sys.stderr, flush=True)
    return fallback
```

#### 3️⃣ `train_gen.py` – generate synthetic training data  
**Why:** Future extensions (e.g., neural‑style root prediction) need a quick way to produce `(root, semantic_vector)` pairs without running the full audio pipeline.  

```python
# train_gen.py
"""
Utility for generating a tiny synthetic training set:
root → normalized semantic vector.
Used by experimental ML modules; kept lightweight and side‑effect free.
"""

import json
from pathlib import Path
from root_semantics import precompute

def generate_training_data(output_path: Path = Path("train_data.json")):
    """Compute normalized semantic vectors for all known roots and dump to JSON."""
    # Re‑use the same root loader as the dialogue engine for consistency
    from dialogue_engine import load_roots
    roots = load_roots()
    vector_table = precompute(roots)          # {root: normalized_vector}
    # Convert numpy arrays to plain Python lists for JSON serialisation
    serialisable = {r: v.tolist() for r, v in vector_table.items()}
    output_path.write_text(json.dumps(serialisable, ensure_ascii=False, indent=2))
    print(f"[train_gen] written {len(serialisable)} training entries to {output_path}")

if __name__ == "__main__":
    generate_training_data()
```

These three changes address the most critical runtime failures, improve data hygiene, and lay groundwork for future learning‑based features while keeping the modifications small, safe, and backward‑compatible.
